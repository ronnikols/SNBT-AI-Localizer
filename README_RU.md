# SNBT AI Localizer

Переводчик файлов квестов FTB для Minecraft (`.snbt`) с поддержкой локальных и облачных моделей. Обеспечивает асинхронную обработку, отказоустойчивость и сохранение форматирования Minecraft.

## Установка

### Рекомендуемые способы
| Платформа       | Команда                          |
|-----------------|----------------------------------|
| Arch Linux AUR  | `yay -S snbt-tr`                 |
| Flatpak         | `flatpak install org.mineai.snbt-tr` |
| pipx            | `pipx install snbt-tr`           |
| PyPI            | `pip install snbt-tr`            |

### Ручная установка
```bash
git clone https://github.com/your-repo/snbt-ai-localizer.git
cd snbt-ai-localizer
pip install -r requirements.txt
```

## Использование

### Способы запуска
- `snbt-tr` - Запускает интерактивный мастер настройки CLI
- `snbt-tr --gui` - Запускает графический интерфейс PyQt6
- `snbt-tr -d /путь/к/квестам` - Пакетная обработка без диалогов

### Примеры
```bash
# Показать доступные модели для Groq
snbt-tr --list-models -p groq

# Перевести папку с квестами через Groq
snbt-tr -d /путь/к/квестам -p groq -k ВАШ_API_КЛЮЧ

# Перевод в режиме Mixed Provider
snbt-tr --mix -d /путь/к/квестам

# Очистить кэш переводов
snbt-tr --clear-cache

# Поиск инстансов Minecraft
snbt-tr --fastdir
```

## Возможности

### Асинхронная обработка
- Неблокирующий ввод/вывод на основе `asyncio` и `httpx.AsyncClient`
- Настраиваемая параллельность (1-10 потоков)
- Адаптивное разбиение на чанки (5 элементов для Ollama, 15 для облачных провайдеров)
- Автоматические задержки между чанками для предотвращения ограничений по частоте запросов

### Отказоустойчивость
- Round-Robin пул ключей с автоматической балансировкой нагрузки
- Невалидные ключи (401/403) удаляются из пула навсегда
- Ключи с ограничением по частоте (429) блокируются с экспоненциальным откатом, начиная с 0.2с и удваивая задержку при каждом повторном ограничении
- Резервный режим: перевод по одному элементу при падении пачки
- Режим Mixed Provider продолжает работу даже при отказе некоторых провайдеров

### Умный кэш
- Кэш на основе SQLite с потокобезопасной блокировкой
- Отдельные таблицы для каждого языка
- Pluralization Guard для предотвращения дублирования запросов для похожих фраз
- Сохранение между чанками в реальном времени

### Защита форматирования Minecraft
- Жёсткая защита тегов, UUID и идентификаторов сущностей через regex
- Временная замена тегов плейсхолдерами во время перевода
- Сохранение всех специфичных для Minecraft кодов форматирования
